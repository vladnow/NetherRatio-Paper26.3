# Установка NetherRatio для Paper 26.3

Версия: 3.0.3-paper26.3.1, Beta. Требуются Paper 26.3 и Java 25.

1. Остановите сервер. Сделайте копию миров и папки plugins/NetherRatio.
2. Удалите прежний JAR NetherRatio из plugins и положите новый. Два JAR одного плагина одновременно не оставляйте.
3. Запустите сервер. Существующий config.yml сохраняется.
4. Для одинаковых координат в обычном мире и Незере выполните /netherratio set 1.
5. При ручном редактировании config.yml примените /netherratio reload.

Пример настройки 1:1: publishing/config-1to1.yml. В архиве также есть исходный пример с 8:1.
Расширенные пары с собственным ratio имеют приоритет над глобальным value.
Калькулятор: /netherratio calc или /netherratio calc 800 -1600. Он доступен игрокам по умолчанию.
Изменение настроек: разрешение netherratio.netherratio, по умолчанию у операторов.

Плагин меняет координаты поиска выхода. Существующие порталы не переносит; окончательное место выхода зависит от поиска и генерации портала сервером.
Ограничения coordinate-bounds не проверяют прогенерацию чанков и безопасность местности.
Folia и Spigot этой сборкой не проверялись.
