[SIZE=6]NetherRatio Port[/SIZE]
Unofficial compatibility port of NetherRatio by xDxRAx, ZyanKLee and the NetherRatio Team.
Original project: https://github.com/ZyanKLee/NetherRatio

[B]Requires Paper 26.3 and Java 25. Spigot and Folia support are not certified.[/B]
Customize Nether/Overworld ratios, per-world pairs and X/Z offsets. Includes coordinate bounds and a portal coordinate calculator.

Stop the server, replace the old NetherRatio JAR in plugins, then start Paper.
Use /netherratio set 1 for a global 1:1 ratio or edit config.yml and run /netherratio reload.
Calculator: /netherratio calc [x z], permission netherratio.calc.
Admin: /netherratio list, set, reload, permission netherratio.netherratio.

Beta: 29 automated logic tests and 16 synthetic event/command checks on Paper 26.3 build 169 passed. Physical client portal crossings remain untested.
